SECTION A

A2: print(-7 // 2)
  You wrote : -3
  Correct   : -4
  Why       : // is floor division. It rounds DOWN toward negative infinity,
              not toward zero. -7 / 2 is -3.5, and rounding down gives -4.
              (7 // 2 gives 3 because 3.5 rounds down to 3.)

A4: print("Python"[1:4], "Python"[::-1])
  You wrote : yth nohtyp
  Correct   : yth nohtyP
  Why       : Reversing keeps each character as it is. The capital P from the
              start of the word is now at the end, and it stays capital.

A7: print(int(3.9), int("12"), float(5))
  You wrote : 4 12 5.0
  Correct   : 3 12 5.0
  Why       : int() CUTS OFF the decimal part. It does not round.
              Use round(3.9) if you want 4.

A10: x = nums.sort(); print(x)
  You wrote : [1, 2, 3]
  Correct   : None
  Why       : .sort() changes the list in place and returns None. So x is
              None. The list nums is sorted, but x is not the list.

A12: print(d.get("b", 0), "a" in d, 1 in d)
  You wrote : AttributeError True False
  Correct   : 0 True False
  Why       : .get() is a real dict method. When the key "b" is missing, it
              returns the default you gave (0) instead of raising an error.
              The other two were right: "a" is a key, 1 is not
              (in checks keys, not values).

A14: print(list(zip([1, 2, 3], ["a", "b"])))
  You wrote : [1, 2, 3, "a", "b"]
  Correct   : [(1, 'a'), (2, 'b')]
  Why       : zip pairs items by position and gives TUPLES. It does not join
              the lists together. It also stops at the shortest list, so the
              3 is dropped.

A15: print(len("café".encode("utf-8")), len("café"))
  You wrote : (blank)
  Correct   : 5 4
  Why       : "café" has 4 characters. Encoded to UTF-8 bytes, é takes 2 bytes
              and the other three letters take 1 each: 1 + 1 + 1 + 2 = 5.

B4: Name two mutable and two immutable types.
  You wrote : Mutable: list, dict. Immutable: tuple, set.

B5: list.sort() vs sorted(list) (partly right)
  You wrote : sort() returns nothing, sorted() returns a value.
  Correct   : sort() changes the original list and returns None.

B6: When to use .get() instead of []?
  You wrote : Don't know.
  Correct   : Use .get() when the key MIGHT NOT EXIST.
  Why       : d["x"] raises a KeyError if x is missing. d.get("x") returns
              None, or a default you choose: d.get("x", 0).

B7: == vs is (partly right)
  You wrote : == compares values, is checks for None.
  Correct   : == checks if values are equal. is checks if two names point to
              the SAME OBJECT in memory.
  Why       : Checking None is the most common use of is, but it is not its
              meaning. Example: [1, 2] == [1, 2] is True, but
              [1, 2] is [1, 2] is False (two separate lists).

B8: What does finally do? (partly right)

  Why       : "Always" is the key word, even after a return or an uncaught

C1:
  def get_total(a, b):
      print(a + b)

  result = get_total(2, 3)

  You wrote : 10
  Correct   : It prints 5, then crashes with TypeError.

  Fix       : Change print(a + b) to return a + b.

C2:
  def add_item(item, items=[]):
      items.append(item)
      return items

  print(add_item(1))
  print(add_item(2))

  You wrote : 1 and 2
  Correct   : [1] then [1, 2]
  Why       : The function returns the list, not the item. The default list
              [] is created ONCE and reused on every call, so the second call
              adds to the same list.
  Fix       :
      def add_item(item, items=None):
          if items is None:
              items = []
          items.append(item)
          return items

C4:
  nums = [1, 2, 3, 4, 5, 6]
  for n in nums:
      if n % 2 == 0:
          nums.remove(n)

  You wrote : [1, 3, 5]
  Correct   : Your output is right, but it is a lucky result.
  Why       : The loop skips items as the list shrinks. It works here only
              because the evens happen to line up that way. Try
              [2, 4, 6, 8]: it leaves [4, 8], not [].
  Fix       : Build a new list instead:
              nums = [n for n in nums if n % 2 != 0]

  You wrote : Does not catch any error because no exception was specified.
  Correct   : It catches EVERY error, and hides all of them.
  Why       : A bare except: catches everything, including typos and Ctrl+C.

              Your reasoning was backwards, so this should be marked lower
