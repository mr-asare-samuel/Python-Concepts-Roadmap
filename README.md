# Python Concepts

My personal Python learning repo. It holds the notes I write, the tasks I solve, 
and the small projects I build while moving from frontend into backend development.

## What's inside
- Notes on core Python: variables, operators, strings, conditionals, loops, 
  lists, tuples, sets, dicts, functions, exceptions, and type hints
- Practice tasks and a fundamentals test
- Small projects: expense tracker, to-do app, bank account simulator, JWT auth

## Goal
Build a strong Python foundation, then go deeper into FastAPI, databases, 
and backend deployment.
